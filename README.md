# 08

**08** is a small web project that was developed for a colleague with a disability. The goal was to create a very simple game that combines visual perception and reaction in an uncomplicated way.

## What is it about?

During the game, the screen is filled with many **0s** and **8s** that switch rapidly. A simple shape is also displayed in the center of the screen.

Two types of changes can occur during the game:

- A visual stimulus briefly appears somewhere in the outer 0/8 field.
- The shape in the center changes, for example from a circle to a square or triangle.

The player responds using the assigned key for each type of event.

## Controls

Before the game starts, the currently assigned keys are shown. The keys can be changed in the settings.

The **game duration** and the **size of the 0/8 fields** can also be adjusted there. The game can be paused or ended at any time by pressing **ESC**.

After the game, a simple results screen is displayed. The result can also be downloaded as a **JPG** image.

## Purpose

08 is intended as a simple visual perception and reaction exercise. The interface was deliberately kept as clear and straightforward as possible so that the game can be used without complicated menus or instructions.

This project is **not a medical diagnostic tool** and is not intended to replace any medical assessment.

## Running the game

08 runs entirely in the browser. To run it locally, simply open `index.html` in a modern web browser.
